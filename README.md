# SKU Graduation Exhibition Backend

서경대학교 졸업전시 운영을 위해 개발된 백엔드 서버입니다.

## Overview

이 프로젝트는 매년 반복되던 졸업전시 사이트 운영 업무를 줄이기 위해 시작되었습니다.
학생들의 작품 정보와 이미지 자료를 메일로 수집하고 수작업으로 정리하던 과정을 시스템화하여, 전시 데이터를 더 구조적으로 관리할 수 있도록 설계했습니다.

현재는 특정 학과의 실제 운영 환경에 맞춰 개발된 프로젝트이며, 범용 SaaS나 외부 사용자를 대상으로 한 완성형 플랫폼은 아닙니다.
다만 졸업전시, 학과 전시, 포트폴리오 아카이브처럼 비슷한 운영 구조를 가진 프로젝트에서 참고할 수 있는 백엔드 구현 사례를 목표로 정리하고 있습니다.

## Background

졸업전시 준비 과정에서는 매년 비슷한 작업이 반복됩니다.

- 학생 및 팀 정보 취합
- 작품 이미지와 설명 수집
- 전시 사이트용 데이터 정리
- 관리자용 수정 요청 반영
- 전시 기간 전후 데이터 관리

기존에는 이 과정이 대부분 수작업으로 이루어졌고, 담당자는 매년 긴 시간을 같은 업무에 반복적으로 사용해야 했습니다.
이 프로젝트는 이러한 반복 업무를 줄이고, 전시 운영 데이터를 시스템 안에서 관리하기 위해 만들어졌습니다.

## Main Responsibilities

이 백엔드 서버는 다음과 같은 기능을 담당합니다.

- 관리자 계정 및 인증 관리
- 학생, 교수, 팀 정보 관리
- 졸업전시 작품 게시글 관리
- 전시 홈 정보 관리
- 이미지 업로드를 위한 S3 연동
- 전시 사이트와 관리자 페이지에서 사용할 API 제공

## Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- Spring Security
- MySQL
- AWS S3 / CloudFront
- Gradle
- GitHub Actions

## Project Scope

이 저장소는 졸업전시 서비스의 백엔드 영역을 다룹니다.
운영 환경, 배포 설정, 민감정보 등은 공개 저장소에 포함하지 않으며, 실제 서비스 환경에 따라 별도로 관리됩니다.

현재 코드는 특정 학과의 운영 흐름을 기준으로 작성되어 있지만, 장기적으로는 유사한 전시 운영 환경에서도 참고할 수 있도록 구조를 정리해가는 중입니다.

## Future Direction

- 학과별 설정을 분리할 수 있는 구조 개선
- API 문서화
- 관리자 업무 흐름 단순화
- 전시 데이터 입력 및 수정 과정 개선
- 유사한 학과/기관 전시 프로젝트에서도 참고 가능한 형태로 정리
